## 1. Subsystem Purpose & Scope

The **Scoring & Feedback Brain** is an asynchronous post-session intelligence engine. Following a completed technical interview, it evaluates the candidate's transcript turns against the deterministic rubric blueprint generated by the Prep Brain.

### Key Outputs:
1. **Calibrated Rubric Scores**: 0.0–10.0 per question with explicit dimensional weightings.
2. **Mistake Callouts**: Concrete architectural oversights, flawed tradeoffs, anti-patterns, or gaps with severity ratings (`minor`, `major`, `critical`).
3. **Actionable Improvement Suggestions**: Specific, constructive advice with recommended study and practice areas.
4. **Behavioral & Communication Summary**: Descriptive feedback on speaking pace, pause distribution, and clarity.

## 4. Division of Labor & Task Routing

| Layer | Assignee | Scope of Work |
|---|---|---|
| **Grading Logic, Synthesis, Orchestration & Verification** | **Antigravity** | • LLM evaluation prompts comparing answers to rubric anchors.<br>• Anchor evaluation (poor: 0–3, good: 4–7, expert: 8–10).<br>• Constructive coaching synthesis and mistake classification.<br>• Validate scoring schema compliance and mathematical weight summation.<br>• Maintain deterministic dry-run tests and prevent regression. |
| **Worker Queue & CLI Harness** | **Codex CLI** | • Async batch runner script (`execution/score_transcript.py`).<br>• Transcript file loading, validation, and JSON report writing.<br>• Task scheduling and dry-run grading harness. |

---

## 5. Execution Guardrails

1. **Deterministic Dry-Run Mode**: Must support `--dry-run` to generate reproducible calibrated scoring outputs without API credits.
2. **Schema Invariant**: Weighted sum of criteria must equal the question score:
   $$\text{Score}(Q_i) = \sum_{j} (\text{weight}_j \times \text{score}_j)$$
3. **Constructive Tone**: Mistake callouts must be actionable, professional, and free of condescending phrasing.
4. **Modality-Agnostic Format**: All outputs must be pure JSON adhering to standard PlaceX event models.
